# RAG 검색 평가 문제와 정답 근거

상태: **평가 질문과 정답 자료 검토 초안**(2026-09-18). 아래 자료 검토는 같은 날의 **로컬 개발 DB 색인**을 읽기 전용으로 확인한 결과다. 현재 검색은 과거 `BLOG_SEARCH` 문서를 제외하며, Q07의 충분성 `false`는 사용자 확인을 거쳐 확정했다. 나머지 질문의 라벨과 정답 자료는 여전히 검토 초안이다. 운영 DB나 배포된 검색 품질을 검증한 결과는 아니다.

## 판정 기준과 자료 범위

- 당시 색인 문서는 64건이며 모두 ACTIVE였다(게시글 40건, 블로그 24건). 현재 검색에서 예전 블로그 색인은 제외된다. 검토는 읽기 전용 트랜잭션에서 문서 본문·chunk·출처를 조회하고 종료했다. 문서와 DB 데이터는 변경하지 않았다.
- **true**는 현재 검색 대상 chunk가 질문의 핵심 답을 직접 뒷받침한다는 뜻이다. **false**는 이 자료 집합에서 질문의 요구를 모두 뒷받침할 근거가 부족하다는 뜻이다. 관련 자료가 일부 있어도 전체 답에 부족하면 false다. **null**은 질문이 넓거나 검색 대상 변경으로 자료를 다시 검토해야 해 충분성을 아직 판정할 수 없다는 뜻이다. 이 라벨은 검색 성공률이나 생성 답변의 정확도와 다르다.
- 게시글 색인에는 제목·작성자·유형·태그·게시글 본문이 들어가지만 댓글은 들어가지 않는다(backend/src/posts/posts.service.ts의 indexPostForRag, backend/scripts/index-board-posts.mjs의 toPostContent). 질문 글이나 댓글만으로 색인된 정답이 있다고 판단하지 않는다.
- 개인 게시글과 블로그는 작성자의 경험·조언에 한해 근거로 쓴다. 공식 선발 기준, 다음 기수 일정, 환불 규정이나 전체 지원자의 합격 확률을 단정하는 근거로 쓰지 않는다.

## 평가 실행 경계

[오프라인 평가 입력](rag-retrieval-evaluation-input.md)에 넣을 Q07의 충분성은 사용자 확인을 거친 `false`이고 관련 내부 정답 문서 ID는 빈 배열이다. 나머지 후보는 Q01~Q05 `true`, Q06·Q08~Q11 `false`이며 아직 사용자 확정 전이다. Q02는 D02와 D02b 두 문서가 함께 정답 자료다. Q11에는 일부 관련 자료 D11을 넣되, 개인 물품 근거가 없어 충분성은 false로 유지한다. 답변에 사용할 수 있는 chunk와 검색 지표의 관련 문서 ID를 혼동하지 않는다.

이 초안은 **로컬 자료 집합을 읽어 만든 후보 정답지**다. 공식 공고·약관·통계가 새로 색인되거나 질문의 뜻을 바꾸면 해당 라벨을 재검토한다. 사용자 검토와 현재 검색 대상의 실제 기존 방식·변경 후보 결과를 확보하기 전에는 Recall@k·MRR·근거 충분성 지표나 배포 합격 여부를 주장하지 않는다.

2026-09-18 추가 읽기 전용 확인: 초안에 적힌 문서 9건은 현재 로컬 DB에 모두 남아 있으며, 이 중 8건은 활성 `BOARD_POST`, D07 한 건은 내부 검색에서 제외한 `BLOG_SEARCH`다. 활성 내부 게시글은 40건이다. Q07 관련 표현을 포함한 D12의 본문과 chunk를 직접 확인해 위 비정답 판단 근거를 기록했다. 이 확인은 기존 방식·변경 후보의 검색 실행을 대신하지 않는다.
